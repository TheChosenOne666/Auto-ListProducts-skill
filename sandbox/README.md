# 上架练习沙盒（practice sandbox）

一个**本地单文件**的假后台，用来在没有真实店铺的情况下把这条链走通一遍：
预检 → 探测 → 写 profile → 试点 → 批量 → 提交前校验 → 抓快照 → 对账。

它不是任何真实店铺：不含真实品牌、真实域名、真实数据，不需要登录，也不涉及任何凭据。
页面自身**不发任何网络请求**（`tests/sandbox_static.py` 会静态断言这一点）。

## 怎么打开

```bash
# 方式一：直接双击 sandbox/admin.html（file:// 即可）
# 方式二：本地起一个静态服务（推荐，路由与 localStorage 行为最接近真实站点）
cd sandbox && python -m http.server 8765
# 然后打开 http://127.0.0.1:8765/admin.html
```

三个路由：`#/new` 新建商品、`#/list` 商品列表、`#/recycle` 回收站。
顶部「重置为种子数据」把本地数据恢复成下面的确定种子。

## 两个板块

顶部「板块」下拉切换 **到店自提 / 快递发货**。这是刻意做成不一样的（真实后台就是这样）：

| | 到店自提 | 快递发货 |
|---|---|---|
| 上架范围 | 必填下拉 | **没有这个字段**，只有一段静态发货说明 |
| SKU 列 | 价格/库存/积分/重量/是否上架/规格图 | 多一列 **体积(m³)**，必填 |
| 是否上架 | 默认开 | **默认关**，一行都不开就拒绝提交 |
| 列表与快照 | 只显示并导出本板块 | 同左，`board` 字段跟着变 |

所以练习时要带 `--board`：`make_queue.py --board express` 会套用该板块的根类目与送券偏移，
`verify_item.py --board express` 会用该板块的列顺序当尺子。

## 埋的坑（全部公开，对照实验必须可复现）

| 坑 | 现象 | 想练到的是什么 |
|---|---|---|
| 重量不标必填但拦住提交 | 表头只有「重量(g)」没有星号，留空点提交会失败并逐列报错 | 探测阶段不能只收集带星号的字段 |
| 同名类目节点 | 一级 `食品/零食` 下面有二级 `食品` | 类目必须逐面板读取 + 选完回读全路径，包含匹配会点错 |
| 速食食品与食品互相包含 | 两个二级标签都含"食品" | 回读全路径断言，而不是匹配片段 |
| 主图必须上传 | 不传主图提交失败 | 上传槽是必填项，回读要拿到存储字节数 |
| 提交需要二次确认 | 点提交先弹确认框，确认后才写入并跳转 `#/list` | 提交动作要有明确的确认点 |
| 库存预填默认值 | 每行库存进来就是 10000，不是要你填 | 默认值是**断言**对象，不是重复输入的对象 |
| 快递板块多了必填的体积列 | 切到快递才出现，且不标必填 | 字段集随板块变，尺子必须跟着换 |
| 快递板块没有上架范围 | 切到快递后该字段消失，换成静态说明 | 不能拿自提的档案去要求快递的表单 |
| 快递板块是否上架默认关 | 一行都不打开就拒绝提交 | 默认状态是"关"时，断言要能发现没打开 |

## 抓快照给 reconcile 用

列表页底部的黑色区块就是 `listings.json` 的形状（`board/capturedAt/source/total/items[].specs[]`），
可以直接抄；也可以用脚本求值 `window.__alpSnapshot()` 拿到同一对象。
把它存成 `listings.json` 后：

```bash
python ../skills/auto-list-products/scripts/reconcile.py \
    --expected queue.json --listings listings.json --board pickup
```

## 配合提交前校验练习

表单填完后，把页面回读值按 `skills/auto-list-products/actual.example.json` 的形状 dump 成
`actual.json`（名称、类目全路径、范围、规格名、规格值顺序、每行价格/库存/积分、上传槽字节数、
勾选数、是否已提交），再跑：

```bash
python ../skills/auto-list-products/scripts/verify_item.py \
    --profile profile.json --queue queue.json --n 1 --actual actual.json
```

沙盒里"重量为空"和"主图未上传"这两类失败，正是这个门应该拦下来的。
